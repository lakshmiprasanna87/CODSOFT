To-Do List Application

Description

To-Do List is a Python-based task management application that allows users to add, view, and remove tasks. It helps users organize their daily activities efficiently.

Features

- Add new tasks
- View all tasks
- Remove completed tasks
- Menu-driven interface

Technologies Used

- Python

How to Run

1. Open the terminal.
2. Navigate to the project folder.
3. Run the following command:

python todo_list.py

4. Select options from the menu to manage tasks.

- Add Task
- View Tasks
