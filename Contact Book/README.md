

Description

Contact Book is a Python application used to store and manage contact information. Users can add, search, update, view, and delete contacts easily.

Features

- Add contacts
- View contacts
- Search contacts
- Update contact details
- Delete contacts
- Menu-driven interface

Technologies Used

- Python
- Dictionary Data Structure

How to Run

1. Open the terminal.
2. Navigate to the project folder.
3. Run the following command:

python contact_book.py

4. Choose options from the menu to manage contacts.

Sample Features

- Store contact name and phone number
- Search contact by name
- Update existing contact
- Delete contact
