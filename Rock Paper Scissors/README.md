Rock Paper Scissors Game

Description

Rock Paper Scissors is a simple Python game where the user plays against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is determined according to the game rules.

Features

- User vs Computer gameplay
- Random computer choice
- Win, Lose, or Draw result
- Easy-to-use interface

Technologies Used

- Python
- random module

How to Run

1. Open the terminal.
2. Navigate to the project folder.
3. Run the following command:

python rock_paper_scissors.py

4. Enter Rock, Paper, or Scissors when prompted.

Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
